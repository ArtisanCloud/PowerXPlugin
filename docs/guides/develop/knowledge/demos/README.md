# 知识库入库与检索演示语料

本目录保存用于本地知识库开发、切块和检索验收的演示文档，不是生产政策或产品配置来源。

## 文档与用途

- [退款与售后政策](./refund-and-after-sales-policy.md)：长文 Markdown 语料。使用默认 `chunk_size=800`、`chunk_overlap=120` 入库时，应生成多个切块；用于验证章节切分、跨章节重叠和语义召回。
- [生产订单手动验证说明](./production-order-manual-verification.md)：独立的测试操作说明。不要与退款政策放到同一个知识空间，否则会成为退款问题的无关召回干扰项。

## 推荐验收

1. 将两篇文档分别入库到各自主题对应的知识空间。
2. 记录退款政策的切块数量；它应大于 1。
3. 用退款文档末尾的检索问题验证目标章节被召回，且生产订单说明不出现在结果中。
4. 用生产订单说明验证“已发起工序后修改计划”的拒绝条件能够被准确召回。
