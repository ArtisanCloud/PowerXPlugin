# 生产订单手动验证说明

## 文档用途

本文档是生产订单领域的独立手动验证说明。它不属于退款与售后知识，应放入生产或工厂运营主题的知识空间，避免污染售后问题的检索结果。

## 一、手动创建大货

1. 创建大货订单时选择一个明确品类。
2. 修改任意节点的计划天数并保存创建。
3. 进入订单详情，确认该节点展示的天数仍是创建时填写的数值。

预期结果：订单应保存自己的计划快照；后续模板变化不应改变这张已创建订单的节点天数。

## 二、小样转大货

1. 从已有小样订单执行转大货操作。
2. 在生成大货订单前修改节点天数。
3. 创建后进入大货订单详情，确认节点天数与本次创建输入一致。

预期结果：小样转大货生成的订单同样拥有独立快照，不能继续引用或覆盖小样订单的计划数值。

## 三、修改模板后的历史订单

1. 修改生产模板中的节点天数。
2. 刷新已经创建的大货订单和由小样转出的订单。
3. 对比订单详情与新的模板配置。

预期结果：历史订单节点天数保持不变；新模板只影响之后新建的订单或明确执行重新计划的订单。

## 四、工厂门户接受订单

1. 在工厂门户打开待处理订单。
2. 修改允许编辑的节点计划。
3. 点击“保存并接受订单”。
4. 检查订单状态、计划记录和审计记录。

预期结果：状态变更、计划保存和审计记录必须同时成功；任一环节失败时，不应出现只改了计划但没有审计或状态不同步的结果。

## 五、生产启动后的计划修改限制

1. 对订单发起任意生产工序。
2. 再尝试修改该订单计划。

预期结果：系统拒绝修改，并清楚说明订单已经进入生产执行阶段。不得通过前端静默覆盖、重新提交旧快照或隐式降级绕过该限制。

## 六、推荐检索问题与预期命中

1. “修改模板会影响已经创建的订单吗？”应命中“修改模板后的历史订单”。
2. “小样转大货后计划是独立的吗？”应命中“小样转大货”。
3. “工厂接受订单后需要看到什么记录？”应命中“工厂门户接受订单”。
4. “生产开始后还能改计划吗？”应命中“生产启动后的计划修改限制”。
