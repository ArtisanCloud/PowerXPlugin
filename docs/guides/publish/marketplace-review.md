# 市场审核与公开上架指南

核对日期：2026-11-09。统一方案为[开发者发布中心与市场对接方案](../../marketplace/plugin-developer-publishing-center-plan.md)，实现范围见[实现设计](../../marketplace/plugin-publisher-implementation.md)。本文描述现有市场浏览器流程及新机器送审的差异，不声明新 publisher 接口已交付。

## 1 身份与职责

开发者使用市场网页登录，市场检查用户、有效开发者身份及插件归属；市场管理员执行批准或驳回，再由有权限人员显式公开上架。宿主管理员、Host API Key、插件业务角色不自动获得市场发布权限。

Framework 提供本地开发工具、资料编辑、送审请求及状态展示；市场是版本、审核、上架和审计的权威。Framework 旧 `publish:*` 角色示例及 Plan/Deploy ID 不替代当前市场身份。

## 2 当前浏览器流程

1. 在市场开发者控制台选择自己的已登记插件，上传实际包字节。成功创建私有草稿，核对版本和所有平台包。
2. 从市场提供的资料选项选择许可证和最低 Core 版本，填写描述、支持地址、安全和隐私说明，按页面要求补齐其他资料。
3. 提交版本审核。已有浏览器接口是 `POST /dev/plugins/{plugin_id}/versions/{version_id}/submit`，相对市场 API root，使用现有会话和 CSRF 规则。
4. 待审核时查看申请状态；驳回后展示原因，补充资料并重新送审，保留历史审计。
5. 管理员核对资料、安全、兼容与许可后批准或驳回；批准不等于公开。
6. 有权限人员显式上架后再核对公共目录和下载字节。下载成功不等于已在 PowerX 安装启用。

现有浏览器送审体使用扁平 PublicationMetadata，最低 Core 版本来自市场精确版本选项；不能自行填写未支持的范围表达式。接口细节以市场现有 OpenAPI 为准。

## 3 状态与允许动作

| 状态 | 含义 | 开发者可做的事 |
| --- | --- | --- |
| draft | 私有草稿 | 核对包和资料，提交审核；当前市场可追加尚不存在的平台 |
| submitted | 待审核 | 查询进度，不追加或替换包 |
| rejected | 已驳回 | 查看原因、修订资料后重提；当前可追加新平台，不覆盖已有平台 |
| approved | 已批准，等待上架 | 查询，仍不可当作公共目录版本 |
| published | 已公开 | 查询和下载；修复已有平台包需新版本 |
| 维护或删除清理中 | 暂不可写 | 显示原因，不由发布工具代执行删除或回滚 |

同版本同平台不允许覆盖。被驳回不代表可自由删除；删除还受引用、提交记录和清理规则约束。

## 4 新机器送审：M2 待实现

新工具使用独立发布凭据与 publications scope，候选接口为 `POST /publisher/plugins/{plugin_id}/versions/{version_id}/submit`，不接受 Cookie 或 Host 凭据代替机器授权。

请求封装为 `metadata` 和 `expected_artifacts`。每个制品引用 `artifact_id` UUID，并带 `os/arch/sha256/size`；提交时核对完整集合，不能只发送主包或平台数量。UUID 是内部引用，界面展示名称、版本和平台。

市场需要持久化集合快照，贯通浏览器送审、管理员审核、包查看和公开上架复核。当前服务主要复核 Version 主制品，尚不能宣称全部附加平台包通过；P07 必须补齐。历史申请缺少快照时明确阻断并显式复核，不补造历史验收结论。

提交使用稳定 operation UUID；重复请求复用同一业务结果。回执 submitted 只表示已入审核流程，不允许客户端写入 approved/published。完整字段、错误、预算和 fixture 随正式 OpenAPI 冻结。

## 5 审核证据

- 缺少扫描报告显示未提供或未执行；已有阻断报告继续阻断，不把缺报告标为通过。
- 签名占位、包摘要和源码提交记录不能代替有效签名或可复现构建证明。
- 所有平台包核对包内身份、目标、存储可读性、摘要和大小，集合变化应拒绝本次提交。
- 第二个包损坏、丢失或被篡改时，即使主包正常也不能提交或公开。
- 逐项记录源码/SDK/CLI/市场版本、操作及请求 ID、预期和实际结果；不记录凭据或签名下载 URL。

联合验收使用主方案 A15—A18；真实市场上传、人工审核、公开下载及宿主启用分开报告。文档对齐不表示这些场景已通过。
